METHOD 01 // GITHUB PAGES (RECOMMENDED)

FREE / PERMANENT

Host directly from your GitHub repository with automatic HTTPS.

  3. Upload or push your index.html file to the root of the repository main branch.
  4. Go to your repository Settings > Pages.
  5. Under Build and deployment, set the Branch to main (or master) and folder to / (root), then click Save.
